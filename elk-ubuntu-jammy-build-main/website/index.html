About This Project

This repository provides a laboratory environment for learning and practicing ELK Stack deployment on Ubuntu 22.04 (Jammy Jellyfish). It is designed for educational purposes and testing, not for production use.

The project includes:

  • Automated installation script for single-host deployment
  • Comprehensive documentation for each component
  • Pre-configured log ingestion pipelines
  • Client configuration templates for Windows and network devices
  • Troubleshooting guides and best practices

Note: This is a laboratory setup for learning purposes. For production deployments, additional security hardening and high-availability configurations are recommended.

ELK Stack Components

Elasticsearch

Distributed search and analytics engine. Stores and indexes all your log data.

  • localhost:9200 (TLS)
  • Self-signed certificates
  • 90-day ILM policy
  • Data streams
Learn More

Logstash

Data processing pipeline that ingests, transforms, and forwards logs to Elasticsearch.

  • Beats: 5044/tcp
  • WEF: 5045/tcp
  • Syslog: 5514/tcp+udp
  • ECS normalization

Visualization and management interface for exploring and analyzing your data.

Quick Installation

Prerequisites

  • OS: Ubuntu 22.04 LTS (Jammy Jellyfish)
  • Privileges: root or sudo access
  • Network: Internet access for package downloads
  • Resources: 8 vCPU / 32 GB RAM / 1 TB SSD (recommended)

Installation Steps

$ git clone https://github.com/yusufarbc/elk-ubuntu-jammy-build.git
$ cd elk-ubuntu-jammy-build
$ chmod +x scripts/install/elk_setup_ubuntu_jammy.sh
$ sudo ./scripts/install/elk_setup_ubuntu_jammy.sh

The script will output Kibana URL, elastic password, and enrollment token upon completion.

Data Flow

  • Logs → Logstash (parsing)
  • Logstash → Elasticsearch (storage)
  • Kibana → Elasticsearch (queries)
  • User → Kibana (visualization)

Network Ports

  • 5044: Beats input
  • 5045: WEF/Winlogbeat
  • 5514: Syslog (TCP/UDP)
  • 5601: Kibana web UI
