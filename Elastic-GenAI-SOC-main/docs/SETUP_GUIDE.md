# Elastic Stack on Kubernetes (ECK) Setup Guide

This guide will walk you through setting up Elasticsearch, Kibana, and Fleet Server on Kubernetes using the ECK Operator.

## Prerequisites
- A running Kubernetes cluster (Minikube, AKS, EKS, etc.)
- `kubectl` installed and configured.
- (Optional) `helm` if you prefer, but we will use raw manifests as requested.

## 1. Install ECK Operator
First, install the Custom Resource Definitions (CRDs) and the operator itself with its RBAC rules.

```powershell
kubectl create -f https://download.elastic.co/downloads/eck/2.11.0/all-in-one.yaml
```

Wait until the operator is running:
```powershell
kubectl -n elastic-system get pods -w
```

## 2. Deploy Components

Apply the manifests in the following order:

### A. Elasticsearch
Deploys a single-node Elasticsearch cluster with persistent storage.
```powershell
kubectl apply -f kubernetes/elasticsearch.yaml
```

**Wait** until it turns green:
```powershell
kubectl get elasticsearch
```

### B. Kibana
Deploys Kibana and connects it to Elasticsearch automatically.
```powershell
kubectl apply -f kubernetes/kibana.yaml
```

**Wait** until it turns green:
```powershell
kubectl get kibana
```

### C. Fleet Server
Deploys the Fleet Server which manages your agents.
```powershell
kubectl apply -f kubernetes/fleet-server.yaml
```

### D. Logstash (Firewall Logs)
Deploys Logstash to receive Syslog traffic (UDP 514) via NodePort 30514.
```powershell
kubectl apply -f kubernetes/logstash.yaml
```

**Firewall Configuration:**
Configure your physical Firewall (e.g., Fortinet, Palo Alto) to send Syslogs to:
*   **IP**: Any Kubernetes Node IP
*   **Port**: 30514 (UDP)

## 3. Access & Security


### Get the `elastic` User Password
ECK automatically generates a password for the `elastic` user. Retrieve it:

```powershell
kubectl get secret quickstart-es-elastic-user -o jsonpath='{.data.elastic}' | ForEach-Object { [System.Text.Encoding]::UTF8.GetString([System.Convert]::FromBase64String($_)) }
```
*(Or on Linux/Bash: `kubectl get secret quickstart-es-elastic-user -o go-template='{{.data.elastic | base64decode}}'`)*

### Access Kibana
Since we used `LoadBalancer`, get the external IP:
```powershell
kubectl get service quickstart-kb-http
```
Open `https://<EXTERNAL-IP>:5601` in your browser.
- **User**: `elastic`
- **Password**: (The one you retrieved above)
- **Note**: Self-signed certificates are used by default, so you will see a browser warning. Proceed unsafely (or configure a real cert later).

## 4. Connect a Windows Agent (Windows Defender Logs)

1.  **Log in to Kibana**.
2.  Go to **Management** -> **Fleet**.
3.  You will see the "Fleet Server" connected.
4.  Click **"Add Agent"**.
5.  Select **"Windows"** as the platform.
6.  Copy the provided PowerShell command. It will look something like this:
    ```powershell
    .\elastic-agent.exe install --url=https://<FLEET-SERVER-IP>:8220 --enrollment-token=<TOKEN> --insecure
    ```
    *Note: Since we are using self-signed certs automatically generated by ECK for the Fleet Server, you MUST add the `--insecure` flag to your install command on the Windows machine, unless you copy the CA cert over.*

7.  Run the command on your Windows machine (Administrator PowerShell).
8.  The agent will register, and you will see it in the Fleet UI.
9.  Add the **"Windows Defender"** integration to the policy to start collecting logs.
